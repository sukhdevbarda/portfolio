## ✨ Features

- 🎨 **Modern design** with glowing gradients, glass cards and a grid background
- 🌗 **Dark and light mode** that follows your system setting
- ⌨️ **Typing effect** that shows different roles
- 🪐 **Orbit animation** of the main tech stack
- 📜 **Scroll reveal** animations for each section
- 📱 **Fully responsive** on mobile, tablet and desktop
- ♿ **Accessible**: keyboard focus styles and reduced-motion support
- ⚡ **Fast and lightweight**: one HTML file, no frameworks, no build step

## 🚀 Run Locally

```bash
# 1. Clone the repo
git clone https://github.com/YOUR_GITHUB_USERNAME/portfolio.git

# 2. Open the folder
cd portfolio

# 3. Open index.html in your browser
```

No install needed. Just open `index.html`.

---

## 🌐 Deploy on GitHub Pages

1. Push the code to GitHub.
2. Go to **Settings → Pages**.
3. Under **Source**, choose the `main` branch and `/ (root)` folder.
4. Click **Save**. Your site will be live at `https://YOUR_GITHUB_USERNAME.github.io/portfolio/`
